- Hurwitz：范数可除代数只有 R、C、H、O（维 1、2、4、8）；S（16 元数）有零因子。
- **O（八元数）非结合** → 它不是「3 个反交换生成元」的 Clifford 代数（Cl(3) 结合、= H⊕H）。
- 「为什么 SU(3) 不是 SU(4）」= 阶梯到 O 停（S 不可除）。
