## 关键锚点（防岔路）

- **⚠️ su(3) 的来源（2026-09-22 突破，绕开八元数）**：不是「缺 ℓ」（八元数路线，已作废），而是 **两个独立 Z₂（手征 Γ + 共轭 K）的自同构 S₃ = SU(3) Weyl 群 → A₂ → su(3)，基本表示 3 = 2⊕1 = 旋量+相位**。核心结果（su(3)=S₃）已立住；唯一性（断裂=手征，子格/谷对偶）是附加、可留后。见 vault [[代数A唯一性卡点：停在H唯一、O缺机制（第3虚单位ℓ无来源）]] 8.6–8.12。
- Hurwitz：范数可除代数只有 R、C、H、O（维 1、2、4、8）；S（16 元数）有零因子。
- **O（八元数）非结合** → 它不是「3 个反交换生成元」的 Clifford 代数（Cl(3) 结合、= H⊕H）。
- **非结合 ≠ 「关系本身」的涌现**（`exp_relation_vs_associator`）：二元关系 k=ij 在 H 内**结合**；非结合 = 三元关联子 [x,y,z]，结构上需要第三个独立元素 e4（= 第 3 虚单位 ℓ）。
- **八元数是强非结合、不是弱结合（融合范畴）**（`exp_associator_pentagon`）：14 种括号给 14 个不同结果（不 coherent）。「因果=顺序」的正确载体 = F 符号（弱结合，coherent），走 v6 的 F 符号路线（融合范畴 → SU(3)_k），**不用先爬八元数**。
- **3D π磁通（Cl(3)）承载不了 SU(3)**（`exp_clifford_su3`）：Cl(3) 的 Lie 代数实维 6（su(2)）≠ su(3) 的 8——「8=8」是维度巧合（数出 8 的老坑）。
- **SU(3) 是自洽的输入（不是推出）**（`exp_su3_consistency`）：引入内部颜色，厄米/范数/U(2) 全保持。推出 ℂ⊕ℍ、输入 M₃，合起来 = 标准模型代数，比 Connes 多推两块。
- **厄米 D 的相位 = sign(D) = Z₂（断裂）**（`exp_hermitian_polar`）：极分解给 Z₂ 对合（U²=I），不是连续 U(1)——「停在 H 唯一」的第二个独立证明。
- **D_R² 交叉项 = σ_y⊗∂_t H_mod（演化项）**（`exp_spectral_action_evolution`）：旧笔记「{σ_z,σ_x}=0 抵消」只在静态 H_mod 成立；动态时交叉项是演化项（时间导数），是「整体动力」（谱作用量给演化方程）的来源。
- **演化项落在 a₄ 阶，不是 a₂ 阶**（`exp_spectral_action_a4`）：交叉项平方 (∂_t H_mod)² ∝ ω²（斜率 1.99）——约束（引力 a₂）与演化（物质 a₄）分层，同源于谱作用量 S=Tr f(D_R²/Λ²)。
- **4D 里演化项进 a₂**（`exp_4d_a2`）：FLRW 标量曲率 R 含时间导数 → a₂=(1/6)∫R 载演化，对照 2D（演化项在 a₄）。「整体动力」4D 有限目标完成，但不解决广义协变性（局域微分同胚）。
- 「为什么 SU(3) 不是 SU(4)」= 阶梯到 O 停（S 不可除）。
